# Review Archive

This directory contains expert perspective reviews for each micro-phase of development.

## Structure

Each micro-phase gets a review document following the naming pattern:
```
phase-X-Y-feature-name-review.md
```

Examples:
- `phase-1-1-simulate-flag-review.md`
- `phase-1-2-explain-mode-review.md`
- `phase-2-5-ai-validation-review.md`

## Review Template

See `REVIEWERS.md` for the complete review template.

Each review evaluates the deliverable from three expert perspectives:
1. **Kelsey Hightower** - Infrastructure & GitOps
2. **Simon Willison** - AI-First Tooling
3. **Jessie Frazelle** - Systems Accessibility

## Review Outcomes

- 🟢 **Pass** - Meets criteria, ship it
- 🟡 **Conditional Pass** - Ship with noted improvements for next phase
- 🔴 **Needs Rework** - Blocking issues must be addressed

## Phase Gate Reviews

Major phases also get comprehensive gate reviews:
- `phase-1-final-review.md`
- `phase-2-final-review.md`
- `phase-3-final-review.md`

These determine if we proceed to the next major phase.
